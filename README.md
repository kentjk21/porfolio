# Kent Katigbak — Interactive Portfolio

Static site (HTML, CSS, vanilla JS). No build step.

## Structure
- `index.html` — page markup
- `css/styles.css` — theme tokens, layout, animations
- `js/data.js` — **all your content** (bio, stats, skills, jobs, focus cards, links). Edit this file to update the site.
- `js/main.js` — rendering, particle background, typing effect, counters, tilt, theme toggle
- `assets/images/` — put photos or logos here

## Run
Open `index.html` in a browser, or serve locally: `python -m http.server`

## Deploy
Upload the folder to GitHub Pages, Netlify or Vercel.
